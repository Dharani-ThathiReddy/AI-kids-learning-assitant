# Kids Learning App – AI-Based Interactive Education Platform

## Overview

Kids Learning App is an interactive educational mobile application designed for children aged 4 to 12 years. The application combines learning and play by using voice input, AI-based story generation, quizzes, and games to create an engaging and personalized learning experience.

---

## Features

### Voice-Based Story Generation

* Users provide a single word through voice input
* The application generates a complete story using AI
* Encourages creativity and imagination

### Story-Based Quiz Generation

* Quizzes are automatically generated from the story
* Improves comprehension and retention
* Questions are adapted based on the child’s age

### Telugu Translation and Read Aloud

* Stories are translated into Telugu
* Read-aloud feature helps with pronunciation and listening skills
* Supports multilingual learning

### Learning Modules

* Basic mathematics quizzes
* General knowledge questions
* Interactive educational mini-games

### Gamification System

* Scoreboard with badges and levels
* Tracks progress and performance
* Encourages continuous learning through rewards

### AI Voice Assistant

* Guides children using voice interaction
* Helps navigate the application
* Provides personalized assistance

---

## Tech Stack

* Frontend: React Native / Mobile UI Framework
* Logic: JavaScript
* AI Integration: Story and quiz generation
* Backend: Node.js 

---

## How It Works

1. The user gives a word using voice input
2. The system processes the input and generates a story
3. The story is displayed and can be read aloud
4. A quiz is generated based on the story
5. The child answers questions and earns scores and badges
6. Progress is tracked and difficulty adapts based on age
